<objective>
Build `snapshot.py`, the I/O adapter that translates githubkit API responses into the frozen `RawSnapshot` dataclass that Phase 1's `derive_snapshot` consumes. The critical bridging challenge (RESEARCH.md Critical Discovery 1) is that the status list API returns `SimpleUser` with no `app_id`/`app_slug` — `_make_status_creator` infers App identity from the login pattern to populate those fields so `is_app_identity()` can succeed. Simultaneously build `gh_fake.py`, the in-memory test substitute that models the four load-bearing GitHub semantic behaviors (status overwrite, label lag, App-vs-workflow creator, merge 204/409), and the contract tests that lock fake/real parity. Addresses IO-02 and IO-06.

Path B contract (iteration-3 revision): `build_snapshot` returns a tuple `(RawSnapshot, dict[int, str])` where the second element is a map from PR number to that PR's head branch ref. This map is populated from `pull_request.head.ref` during the per-PR `pulls.get` call. The executor (Plan 02-03) consumes this map for its `repos.merge(base=branch, head="develop")` call, keeping the pure-layer `PRState` unchanged. `snapshot.py` does NOT touch `rocm_mq.state` — the auxiliary map is a parallel return value, not a new dataclass field.

Purpose: `snapshot.py` closes the loop between real GitHub API data and Phase 1's pure derive → decide pipeline. `gh_fake.py` enables Plan 02-03 (executor) and Plan 02-04 (CLI) to run without network access. Contract tests prevent the fake from silently diverging from real GitHub semantics. The pr_branches return value plumbs PR-branch I/O concerns without contaminating the pure decision model.

Output: `build_snapshot(client, config)` returns `(RawSnapshot, dict[int, str])` whose `RawSnapshot.prs` contain correctly-typed frozen dataclasses AND whose second tuple element maps every PR number in the snapshot to its head branch ref; `FakeGitHub` passes all four contract tests; `FakePR` carries a `branch: str` field so `pulls.get(...).head.ref` returns the correct value in fake mode.
