## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| token → GitHubClient | Pre-minted installation token arrives as env var (GHA step); never minted in Python |
| GitHubClient.rest → GitHub API | All mutations (labels, statuses, squash) cross this boundary |
| apps.get_authenticated() → AppIdentity | Startup identity resolution; trusted GitHub API response |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Spoofing | resolve_app_identity: slug/bot_user_id returned from API | mitigate | AppIdentity used downstream in is_app_identity triple-AND; resolve_app_identity is a startup call, not a per-cycle call; results stored in config, not re-fetched per cycle |
| T-02-01-02 | Denial of Service | SecondaryRateLimitExceeded during retry loop | mitigate | max_retries=3 cap; exponential sleep via e.retry_after.total_seconds(); final attempt re-raises, allowing cycle to abort cleanly |
| T-02-01-03 | Tampering | Non-rate-limit RequestFailed silently swallowed in retry loop | mitigate | Only SecondaryRateLimitExceeded triggers retry; all other exceptions propagate immediately; test_retry_non_rate_limit_exception_propagates_immediately covers this |
| T-02-01-04 | Information Disclosure | App private key in Python memory | accept | gh.py accepts pre-minted token (str); private key never touches Python — handled by actions/create-github-app-token@v3 in GHA (CLAUDE.md pattern decision); no key material in this codebase |
</threat_model>
