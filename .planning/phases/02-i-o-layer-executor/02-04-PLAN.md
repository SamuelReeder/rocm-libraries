Build `cmd_process.py` — the CLI glue that orchestrates the full RFC §4.9 read → decide → execute loop against either the real GitHub API or the in-memory `FakeGitHub`. The entrypoint uses `argparse.add_subparsers(dest="subcommand", required=True)` so the `process-cycle` token in `python -m rocm_mq process-cycle --fake` is consumed as a proper subcommand (scales to Phase 3 when `mq-handler` and other entrypoints are added). The pure layer never sees the branch map.
